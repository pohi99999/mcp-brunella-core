# Track: Documentation & Infrastructure Synchronization

## Cél
A projekt teljes könyvtárszerkezetének, eszközkészletének és dokumentációjának feltérképezése, szabványosítása és szinkronizálása a GitHub repoval. Az indítási folyamatok (start.bat) automatizálása a külső függőségek (Ollama, AnythingLLM) kezelésével.

## Hatókör
- **Fájlrendszer:** konyvtarfa.md generálása és fenntartása.
- **Eszközök:** Toolskeszlet.md (MCP eszközök leltára).
- **Verziókezelés:** Helyi repo szinkronizálása a GitHub-bal.
- **Dokumentáció:** README.md, mag.md frissítése.
- **Automatizálás:** start.bat bővítése (Ollama, AnythingLLM check).
