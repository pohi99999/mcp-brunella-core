# Implementacios Terv: Nova Multi-Agent Gatekeeper Architektura

## Fazisok

### 1. Gatekeeper alap
- A gatekeeper agent routing szabalyainak formalizalasa.
- Chat trigger, intent-elemzes es sub-workflow kivalasztas.

### 2. Specialista agensek
- Sales, Research, Document es Execution sub-workflow-k leirasa.
- Parhuzamos futasi es merge szabalyok definialasa.

### 3. Shared memory es human gate
- Window buffer, vector store es shared state szerepenek rogzitese.
- Slack vagy email alapú emberi jovahagyasi megszakitasi pontok.

### 4. Tooling es validacio
- CRM, email, calendar, scraping es execution tool-pontok kijelolese.
- Diagnosztika, debug es operatori megfigyelhetoseg kovetelmenyei.
