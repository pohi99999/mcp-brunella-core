# 🚀 EKR Keresés - GYORS INDÍTÁS

## ⚡ Leggyorsabb Módszer (AJÁNLOTT)

Egyszerűen mondd Claude-nak:

```
"Futtasd le az összes EKR keresést a 9 kulcsszóval"
```

Ennyi! Claude automatikusan:
1. ✅ Használja a már nyitott böngészőt (nincs új belépés)
2. ✅ Végigmegy mind a 9 kulcsszón
3. ✅ Naplózza az eredményeket
4. ✅ Generál JSON + Markdown riportot
