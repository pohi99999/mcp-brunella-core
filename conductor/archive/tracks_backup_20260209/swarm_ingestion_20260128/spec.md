# Track: Swarm Ingestion Foundation

## Cél
A "Harvester Swarm" alapjainak lefektetése. Egy olyan folyamat létrehozása, ahol egy ügynök adatot gyűjt a webről, az Adattudós megtisztítja, és a rendszer elmenti a hosszú távú memóriájába.

## Lépések
- [ ] **Task 1: Browser Tool megerősítése.** Ellenőrizni, hogy a `browser_navigate` képes-e szöveget kinyerni az Adattudós számára.
- [ ] **Task 2: Ingestion Pipeline kódolása.** Egy új tool vagy ügynök-logika, ami láncolja a Browser -> Refiner -> Knowledge folyamatot.
- [ ] **Task 3: Első "Trend Pásztázás".** Egy konkrét téma (pl. "AI Agents trends 2026") automatizált feldolgozása.
