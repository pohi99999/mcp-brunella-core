# Toura Project Analysis & Blueprint

## Project Overview
Toura is a multi-layered application integrating Cloudflare Workers for edge logic and a Python-based research agent. It serves as the primary development hub for the Nova ecosystem.

## Architecture Patterns
- **Backend:** Cloudflare Workers (TypeScript)
- **Frontend:** Next.js
- **Research Agent:** Python (FastAPI/Script)
- **Infrastructure:** Cloudflare D1 (SQL), R2 (Storage), Wrangler

## Core Workflows

### 1. Document Analysis & Ingestion
- **Trigger:** HTTP request to Worker or Researcher.
- **Components:** `src/index.ts`, `src/utils/documentProcessor.ts`, `researcher/main.py`.
- **Flow:** User uploads document -> Worker processes metadata -> Researcher performs deep analysis -> Data stored in D1/R2.

### 2. Multi-Agent Coordination (Nova Integration)
- **Trigger:** Complex query from Frontend.
- **Components:** Nova Subtracks (`gatekeeper`, `briefing`).
- **Flow:** Request hits Gatekeeper -> Task decomposed -> Delegated to specialized agents (Briefing, Researcher) -> Results aggregated.
