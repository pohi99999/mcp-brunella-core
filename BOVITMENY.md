### 🧩 Gemini CLI Bővítmények - Képességek és Használat

**1. `skill-creator` (Készség-létrehozó)**
*   **Funkció:** Segít új készségeket (skill) létrehozni vagy meglévőket frissíteni a Gemini CLI számára.
*   **Használat:** Ha a Gemini CLI képességeit bővíteni szeretnéd egy új, speciális tudásterülettel vagy munkafolyamattal.

**2. `apify-ultimate-scraper` (Apify Végső Webkaparó)**
*   **Funkció:** Univerzális, AI-alapú webkaparó a legtöbb platformról (Instagram, Facebook, TikTok, YouTube, Google Maps, stb.).
*   **Használat:** Lead generálásra, márkafigyelésre, versenytárselemzésre, trendkutatásra, vagy bármilyen adatkinyerési feladatra.

**3. `apify-trend-analysis` (Apify Trendelemzés)**
*   **Funkció:** Feltörekvő trendek felfedezése és követése a Google Trends, Instagram, Facebook, YouTube és TikTok platformokon.
*   **Használat:** Tartalomstratégia kialakításához és piaci elemzésekhez.

**4. `apify-market-research` (Apify Piackutatás)**
*   **Funkció:** Piaci feltételek, földrajzi lehetőségek, árazás, fogyasztói magatartás elemzése a Google Maps, Facebook, Instagram, Booking.com, TripAdvisor adatai alapján.
*   **Használat:** Részletes piackutatáshoz és üzleti döntések alátámasztásához.

**5. `apify-lead-generation` (Apify Lead Generálás)**
*   **Funkció:** B2B/B2C leadek generálása weboldalak, Google Maps, Instagram, TikTok, Facebook, LinkedIn, YouTube és Google Kereső adatainak kaparásával.
*   **Használat:** Prospektusok felkutatására, lead listák építésére, kapcsolati adatok gazdagítására, értékesítési megkeresésekhez.

**6. `apify-influencer-discovery` (Apify Influenszer Keresés)**
*   **Funkció:** Influenszerek keresése és értékelése márkapartnerségekhez, hitelesség ellenőrzése, együttműködések teljesítményének követése.
*   **Használat:** Marketing kampányokhoz és befolyásolók azonosításához.

**7. `apify-ecommerce` (Apify E-kereskedelem)**
*   **Funkció:** E-kereskedelmi adatok kaparása árfigyeléshez, vásárlói véleményekhez és eladók felkutatásához az Amazon, Walmart, eBay és 50+ piactéren.
*   **Használat:** Árfigyelésre, versenytársak követésére, termékkutatásra, vélemények elemzésére.

**8. `apify-content-analytics` (Apify Tartalomelemzés)**
*   **Funkció:** Elkötelezettségi mutatók követése, kampány ROI mérése és tartalom teljesítményének elemzése az Instagram, Facebook, YouTube és TikTok platformokon.
*   **Használat:** Tartalomstratégia optimalizálásához és kampányelemzéshez.

**9. `apify-competitor-intelligence` (Apify Versenytárs Elemzés)**
*   **Funkció:** Versenytársak stratégiáinak, tartalmainak, árazásának, hirdetéseinek és piaci pozíciójának elemzése számos platformon.
*   **Használat:** Versenytársak megfigyelésére és piaci előny szerzésére.

**10. `apify-brand-reputation-monitoring` (Apify Márka Hírnév Figyelés)**
*   **Funkció:** Vélemények, értékelések, hangulat és márkaemlítések követése a Google Maps, Booking.com, TripAdvisor, Facebook, Instagram, YouTube és TikTok platformokon.
*   **Használat:** Márka hírnevének figyelésére, ügyfél visszajelzések gyűjtésére.

**11. `apify-audience-analysis` (Apify Közönségelemzés)**
*   **Funkció:** Közönség demográfiai adatainak, preferenciáinak, viselkedési mintáinak és elkötelezettségének elemzése a Facebook, Instagram, YouTube és TikTok platformokon.
*   **Használat:** Célközönség jobb megértéséhez és marketing célzás optimalizálásához.

**12. `apify-actorization` (Apify Actorizálás)**
*   **Funkció:** Meglévő projektek (JS/TS, Python, vagy bármilyen nyelv) Apify Actorokká alakítása.
*   **Használat:** Kód Apify platformra való migrálásához, CLI eszközök Actorokká alakításához.

**13. `apify-actor-development` (Apify Actor Fejlesztés)**
*   **Funkció:** Apify Actorok (szerver nélküli felhőprogramok) fejlesztése, debugolása és telepítése webkaparáshoz, automatizáláshoz és adatfeldolgozáshoz.
*   **Használat:** Új Actorok létrehozásához, meglévők módosításához vagy Actor kódok hibaelhárításához.

**14. `chrome-devtools` (Chrome DevTools)**
*   **Funkció:** Hatékony hibakeresés, böngésző automatizálás, teljesítményelemzés és hálózati kérések vizsgálata a Chrome DevTools protokollon keresztül.
*   **Használat:** Weboldalak hibakereséséhez, böngésző interakciók automatizálásához.

**15. `tdd-workflow` (TDD Munkafolyamat)**
*   **Funkció:** A tesztvezérelt fejlesztés (TDD) kikényszerítése, legalább 80%-os tesztlefedettséggel.
*   **Használat:** Új funkciók írásához, hibák javításához vagy kód refaktorálásához.

**16. `strategic-compact` (Stratégiai Kompaktálás)**
*   **Funkció:** Javasolja a manuális kontextus kompaktálását logikai időközönként, a kontextus megőrzése érdekében.
*   **Használat:** Hosszú munkamenetek során a kontextus méretének menedzseléséhez.

**17. `springboot-verification` (Spring Boot Verifikáció)**
*   **Funkció:** Verifikációs ciklus Spring Boot projektekhez: build, statikus analízis, tesztek lefedettséggel, biztonsági ellenőrzések.
*   **Használat:** Release vagy PR előtt a minőségbiztosításhoz.

**18. `springboot-tdd` (Spring Boot TDD)**
*   **Funkció:** Tesztvezérelt fejlesztés Spring Boot alkalmazásokhoz JUnit 5, Mockito, MockMvc, Testcontainers és JaCoCo használatával.
*   **Használat:** Funkciók hozzáadásához, hibák javításához vagy refaktoráláshoz.

**19. `springboot-security` (Spring Boot Biztonság)**
*   **Funkció:** Spring Security legjobb gyakorlatok: autentikáció/autorizáció, validáció, CSRF, titkok kezelése, fejlécek, sebességkorlátozás és függőségi biztonság.
*   **Használat:** Spring Boot alapú Java szolgáltatások biztonságos fejlesztéséhez.

**20. `springboot-patterns` (Spring Boot Minták)**
*   **Funkció:** Spring Boot architektúra minták, REST API tervezés, réteges szolgáltatások, adatelérés, gyorsítótárazás, aszinkron feldolgozás és naplózás.
*   **Használat:** Java Spring Boot backend fejlesztési feladatokhoz.

**21. `security-review` (Biztonsági Felülvizsgálat)**
*   **Funkció:** Átfogó biztonsági ellenőrzési lista és minták.
*   **Használat:** Hitelesítés hozzáadásakor, felhasználói bevitel kezelésekor, titkokkal való munka során, API végpontok létrehozásakor vagy érzékeny funkciók implementálásakor.

**22. `python-testing` (Python Tesztelés)**
*   **Funkció:** Python tesztelési stratégiák pytest-tel, TDD módszertannal, fixture-ökkel, mockinggal, parametrizálással és lefedettségi követelményekkel.
*   **Használat:** Python kód teszteléséhez.

**23. `python-patterns` (Python Minták)**
*   **Funkció:** Pythonikus idiómák, PEP 8 szabványok és legjobb gyakorlatok robusztus, hatékony és karbantartható Python alkalmazások építéséhez.
*   **Használat:** Python kód írásához.

**24. `postgres-patterns` (PostgreSQL Minták)**

*   **Használat:** PostgreSQL adatbázisokkal való munkához.

**25. `nutrient-document-processing` (Nutrient Dokumentumfeldolgozás)**

*   **Használat:** PDF-ek, DOCX, XLSX, PPTX, HTML és képek kezeléséhez.

**26. `jpa-patterns` (JPA Minták)**

**27. `java-coding-standards` (Java Kódolási Szabványok)**
