# Track: Brunella CLI Verification & Parity

## Cél
A saját fejlesztésű Brunella CLI (src/cli.ts) átfogó auditálása, működésének ellenőrzése és a dokumentáció (Toolskeszlet.md) frissítése. A cél a Gemini CLI szintjének elérése, különös tekintettel a Conductor integrációra.

## Fókuszterületek
1. **Entry Point & Build:** Biztosítani, hogy a runella parancs a megfelelő kódot futtassa.
2. **Conductor Integráció:** A /conductor:* parancsok (status, setup, implement) működőképessége.
3. **Core Funkciók:** Memória (/memory), Tools (/run), Fájlműveletek.
4. **Dokumentáció:** A CLI képességeinek rögzítése a Toolskeszlet.md-ben.
