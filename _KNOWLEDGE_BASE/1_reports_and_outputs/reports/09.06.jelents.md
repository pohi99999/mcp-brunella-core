### **2\. Legjobb CLI technikák/workflow-k**

#### **2.1. Technika: Python Környezeti Változók Kezelése ModuleNotFoundError Elhárítására**

Gyakori CLI probléma, amikor egy script nem találja a telepített csomagokat a több párhuzamos Python verzió miatt. A google\_integration\_state.md dokumentum egy konkrét ilyen esetet ír le.

* **Probléma Demonstrálása:**  
  Bash  
  \# A script futtatása hibát dob, mert a rendszer Pythona nem látja a csomagokat  
  python G:\\Brunella\\authenticate\_google.py   
  \# Hiba: ModuleNotFoundError: No module named 'google'

* **Megoldási Workflow:**  
  1. **Helyes Python Interpreter Azonosítása:** Győződj meg róla, hogy melyik Python verzióhoz telepítetted a szükséges csomagokat.  
  2. **site-packages Könyvtár Megkeresése:** Keresd meg a csomagok telepítési helyét. Ez általában a Python telepítési mappáján belül a Lib/site-packages útvonalon található.  
     * *Példa (a dokumentumból):* C:\\Users\\Felhasznalo\\AppData\\Local\\Packages\\PythonSoftwareFoundation.Python.3.11\_qbz5n2kfra8p0\\LocalCache\\local-packages\\Python311\\site-packages  
  3. **PYTHONPATH Beállítása és Futtatás:** Add meg a Pythonnak a csomagok helyét a PYTHONPATH környezeti változóval a parancs futtatása előtt.  
  * **Telepítés (Windows CMD):**  
    Bash  
    set PYTHONPATH=C:\\...\[útvonal\]...\\site-packages && python G:\\Brunella\\authenticate\_google.py

  * **Telepítés (Linux/Git Bash/PowerShell):**  
    Bash  
    PYTHONPATH="/.../\[útvonal\]/.../site-packages" python G:/Brunella/authenticate\_google.py

* **Integráció Geminivel:** Gemini ügynökök képesek diagnosztizálni az ilyen hibákat és javaslatot tenni a helyes PYTHONPATH beállítására, ha megkapják a hibaüzenetet és a releváns fájlrendszer-struktúrát.
