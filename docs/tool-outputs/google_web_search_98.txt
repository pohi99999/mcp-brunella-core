The Apify MCP Server provides a "Call Actor" tool, which is a generic tool to call any Apify Actor by its ID and input.[1]

In addition to the generic "Call Actor" tool, the Apify MCP Server offers several helper tools for managing Actors and accessing Apify resources:
*   **Actor discovery and management:** Tools to search for Actors in the Apify Store, retrieve detailed information about a specific Actor (e.g., `get-actor-details`), and dynamically add or remove Actors as available tools.[2][3][1]
*   **Apify documentation:** Tools to search the Apify documentation and fetch the full content of documentation pages.[2][1]
*   **Actor runs:** Tools to get detailed information about a specific Actor run, list Actor runs (filterable by status), and retrieve logs for a specific Actor run.[2][1]
*   **Data storage:** Tools to get metadata about a specific dataset, retrieve dataset items with pagination/filtering, list all datasets, get the JSON schema of dataset items, get metadata for a key-value store, list keys in a specific key-value store, get a value by key from a key-value store, and list all key-value stores.[2][1]

Furthermore, any Apify Actor can be used as a tool, with its name being the full Actor name (e.g., `apify/rag-web-browser`).[2][3]
