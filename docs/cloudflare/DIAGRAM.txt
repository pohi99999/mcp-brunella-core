Common Issues:
  HTTP 401 (Unauthorized)
    ├─ Token invalid/expired
    ├─ Server didn't reload .env
    └─ Fix: Restart Node.js backend (npm run dev)

  HTTP 502 (Bad Gateway)
    ├─ AI Gateway URL wrong
    ├─ Worker not responding
    └─ Fix: Check CLOUDFLARE_WORKER_URL + worker deploy status

  "unhealthy" despite valid token
    ├─ Token missing Workers AI scope
    └─ Fix: Generate new token (Workers AI + Scripts + Account Settings)

Token Verification:
  curl -s "https://api.cloudflare.com/client/v4/user/tokens/verify" \
    -H "Authorization: Bearer $CF_API_TOKEN" | python -m json.tool

  Expected: "This API Token is valid and active"

Tunnel Start:
  cloudflared tunnel --url http://localhost:3000

D1 Database Create:
  wrangler d1 create cean-tasks

Vectorize Index Create:
  wrangler vectorize create cean-embeddings --dimensions=1536 --metric=cosine

KV Namespace Create:
  wrangler kv:namespace create cean-cache
