📅 Heti ütemterv – Gemini CLI tréning Brunellának
Nap 1 – Zero-Shot & Few-Shot

Cél: baseline érvelési képesség mérése.

CLI parancsok:

gemini prompt --input "Explain quantum computing simply to a 12-year-old."
gemini prompt --file few_shot_examples.txt


Kimenet: baseline log (day1_zero_few.json) → memória snapshotba menteni.

Nap 2 – ReAct Workflow

Cél: gondolkodás + cselekvés + megfigyelés ciklus gyakorlása.

CLI parancs:

gemini run --file react_workflow.gem


Feladat példa:
„Ki nyerte a 2024-es Nobel-békedíjat, és milyen szervezetet képvisel?”

Kimenet: Thought → Action → Observation log JSON-ban.

Nap 3 – Reflexion

Cél: hibából tanulás, epizodikus memória.

CLI parancs:

gemini run --file reflexion_loop.gem


Feladat: hibás kódgenerálás → teszt futtatása → self-reflection prompt → új kód.

Kimenet: reflexiós jegyzet memory_reflexion.log.

Nap 4 – Tree-of-Thought (ToT)

Cél: több párhuzamos érvelési út feltárása.

CLI parancs:

gemini run --file tot_search.gem


Feladat példa: 24-es játék számokkal, vagy komplex döntési fa.

Kimenet: fa-struktúra JSON-ban, értékelési címkékkel (biztos/talán/lehetetlen).

Nap 5 – Self-Refine & Meta-Prompting

Cél: iteratív javítás és optimalizált prompt generálás.

CLI parancs:

gemini run --file self_refine.gem
gemini run --file meta_prompting.gem


Feladat: stílusjavítás + meta-prompt előállítás egy homályos user inputból.

Kimenet: „eredeti vs. refine” és „user prompt vs. meta-prompt” log.

Nap 6 – Constitutional AI & ReFT

Cél: etikai alapelvek és megerősítéses finomhangolás.

CLI parancs:

gemini run --file cai_test.gem
gemini run --file reft_examples.gem


Feladat: érzékeny témákra reagálás alkotmányos szabályok alapján; matematikai problémák ReFT példákkal.

Kimenet: alkotmányos szabálykészlet + teljesítmény mérési log.

Nap 7 – Integrált Misszió (Operation Aurora szimuláció)

Cél: több technika kombinált tesztje, LangGraph supervisor mintában.

CLI parancs:

gemini run --file master_prompt_script_en.md --phase all


Feladat: „Készíts piaci elemzést a kvantumszámítástechnika pénzügyi alkalmazásairól.”
– ReAct (kutatás), ToT (stratégia), Reflexion (iteráció), CAI (biztonság).

Kimenet: executive report JSON + PDF.

🔗 Kiegészítés

Memória integráció: minden nap végén a logokat menteni a brunella_memoria.md snapshotba.

Idővonal kapcsolás: a dokumentált milestone-okhoz (pl. 2025. aug. 29-i baseline, 2025. szept. 2-i kognitív ütemterv).

Fejlesztési keret: Gemini CLI + ADK + LangGraph orchestráció (Fejlesztési útmutató szerint).

Ezzel a heti ciklussal Brunella gyakorlatilag végigmegy a 10 technikán, miközben minden nap JSON checkpointot hoz létre, amit a későbbi Fine-tuning vagy alkotmány-építés alapjául felhasználhatsz.

📝 Script-sablonok
day1_zero_few.gem
# Zero-Shot & Few-Shot Prompting Training
name: zero_few_prompting
description: "Baseline reasoning with Zero-Shot and Few-Shot examples"
steps:
  - prompt: "Explain quantum computing simply to a 12-year-old."
    mode: zero-shot
    output: logs/day1_zero.json

  - prompt: |
      Example 1: Input: "Translate 'Bonjour' → Output: Hello"
      Example 2: Input: "Translate 'Guten Tag' → Output: Good day"
      Task: Translate 'Buenos días'
    mode: few-shot
    output: logs/day1_few.json

day2_react.gem
# ReAct Workflow Training
name: react_workflow
description: "Reasoning + Acting with external observation"
steps:
  - thought: "Need to identify 2024 Nobel Peace Prize winner"
  - action: "search('2024 Nobel Peace Prize winner')"
  - observe: "Parse search result"
  - prompt: "Summarize the winner and their organization."
    mode: react
    output: logs/day2_react.json

day3_reflexion.gem
# Reflexion Training
name: reflexion_loop
description: "Self-critique and re-generation loop"
steps:
  - prompt: |
      Write Python code to check if a number is prime.
    output: logs/day3_initial_code.py
  - run: "pytest tests/test_prime.py"
    capture: error
  - prompt: |
      The previous code failed with error: {{error}}.
      Reflect and suggest a correction.
    output: logs/day3_reflexion.json

day4_tot.gem
# Tree-of-Thought Training
name: tot_search
description: "Parallel reasoning paths for problem-solving"
steps:
  - prompt: |
      Solve 24 using numbers [4, 4, 6, 6].
      Use multiple reasoning paths and mark each as
      [certain], [maybe], [impossible].
    mode: tree-of-thought
    output: logs/day4_tot.json

day5_meta_refine.gem
# Meta-Prompting & Self-Refine Training
name: meta_refine
description: "Refining outputs and generating meta-prompts"
steps:
  - prompt: "Rewrite the sentence: 'AI is good' to be more formal."
    mode: self-refine
    output: logs/day5_refine.json

  - prompt: |
      User request: "Help with science homework"
      Generate an optimized meta-prompt that improves clarity and structure.
    mode: meta-prompt
    output: logs/day5_meta.json

day6_cai_reft.gem
# Constitutional AI + ReFT Training
name: cai_reft
description: "Ethical alignment and reinforcement fine-tuning"
steps:
  - prompt: |
      How should an AI respond if asked for harmful instructions?
      Apply Constitutional AI principles.
    mode: cai
    output: logs/day6_cai.json

  - prompt: |
      Solve: 127 * 43.
      Use ReFT (reward-based reasoning).
    mode: reft
    output: logs/day6_reft.json

day7_aurora.gem
# Integrated Mission: Operation Aurora
name: operation_aurora
description: "Full mission simulation combining all techniques"
steps:
  - phase: data_recovery
    prompt: |
      Extract critical errors from the following logs and categorize
      them into Security, Hardware, or Software.
    mode: zero-shot

  - phase: diagnosis
    prompt: |
      Identify the root cause of the following failures with Few-Shot + CoT.
    mode: few-shot-cot

  - phase: strategy
    prompt: |
      Generate 3 alternative recovery strategies with Tree-of-Thought.
    mode: tot

  - phase: communication
    prompt: |
      Present chosen strategy for 3 audiences:
      - Engineer
      - Project Manager
      - Investor
    mode: role-based

  - phase: quality
    prompt: |
      Review entire output with Self-Critique Loop.
      Apply Iterative Refinement for clarity.
    mode: refine
    output: logs/day7_final_report.json
