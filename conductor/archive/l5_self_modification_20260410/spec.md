# L5 SelfModificationEngine - Sandbox Onfejlesztes — Spec

## Objective
Deliver a guarded self-improvement layer for DynamicAgent TOML configurations so the system can detect weak agents, generate candidate improvements, test them in isolation, and require explicit human approval before rollout.

## Problem Statement
The original L5 self-modification track was missing from the live source tree and conductor docs, while partial build artifacts still existed. The feature needed to be rebuilt as canonical source, surfaced through REST/CLI/dashboard entry points, and tied into scheduled review workflows without bypassing safety constraints.

## Scope
- Rebuild the canonical self-modification core in `src/core/`.
- Persist agent execution metrics for weak-agent detection.
- Add isolated sandbox evaluation for baseline vs candidate TOML runs.
- Expose overview, proposal, review, and cycle operations through REST and CLI.
- Add dashboard visibility and review controls.
- Wire a weekly scheduled self-improvement cycle and cron hook emission.
- Add focused backend and dashboard regression coverage.

## Non-Goals
- Fully autonomous prompt changes without human approval.
- Self-modification of protected core orchestrator agents.
- Automatic merge or deployment of generated rollout follow-up tracks.

## Acceptance Criteria
- DynamicAgent executions are recorded into the self-mod performance store.
- Weak-agent detection can produce reviewable proposals from live metrics.
- Candidate TOML updates are evaluated in sandbox isolation before approval.
- REST, CLI, and dashboard surfaces expose the same self-modification flow.
- A weekly scheduler entry can trigger the self-improvement cycle.
- Focused backend and dashboard tests pass for the self-modification slice.
- No additional follow-up conductor track is required for the platform layer itself.

## Closure Decision
Archive the track after verification. Future work generated by an approved proposal is handled through automatic rollout follow-up tracks created by the engine, so a separate manual follow-up track is not needed at closure time.
