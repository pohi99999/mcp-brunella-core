# Brunella Personal Assistant — Windows MVP Foundation

## Objective
Create the first productized foundation for a Windows-first local AI assistant built on Brunella. The assistant must support Hungarian interaction, cloud/local model switching, long-term memory, GraphRAG, self-reflection, and computer-use automation.

## User Goal
The user wants a modern, Hungarian, local PC assistant that can:
- run on Windows,
- control files and system workflows,
- talk with a female Hungarian voice,
- accept voice and text input,
- use GraphRAG and long-term memory,
- self-evaluate and store lessons,
- switch between GitHub Models and local Ollama,
- perform computer-use and automation.

## Scope (Phase 1)
1. Define the recommended target architecture.
2. Expose runtime readiness from the current Brunella stack.
3. Add a dashboard panel for the assistant blueprint.
4. Add a CLI entry point for assistant readiness/roadmap.
5. Document the phased implementation path.

## Non-Goals (Phase 1)
- Full offline STT/TTS replacement.
- Full desktop packaging release.
- Final persona/branding polish.
- Complete OS automation orchestration layer.

## Success Criteria
- Assistant blueprint available via backend API.
- Dashboard panel summarizes readiness and roadmap.
- CLI command prints the same architecture/readiness data.
- Documentation clearly explains the best solution path.
