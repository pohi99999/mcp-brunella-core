# Technológiai Stack

## Nyelvek
- TypeScript
- Python
- Rust (Tauri)

## Frontend
- React
- TailwindCSS
- Vite

## Backend és Orchestration
- Express.js (Node.js)
- FastAPI (Python)
- Socket.IO (Valós idejû kommunikáció)
- Model Context Protocol (MCP)

## Adatbázisok és Tárolás
- SQLite (Metaadatok és feladatkezelés)
- LanceDB (Vektoros adatbázis RAG-hoz)

## Cloudflare Integrációk
- **Cloudflare Workers**: Edge computing és orchestration.
- **Cloudflare Tunnel**: Biztonságos távoli hozzáférés.
- **AI Gateway**: LLM kérések menedzselése, cache és rate limiting.
- **Workers KV / D1 / R2**: Elosztott tárolás és adatbázisok.
