# Specifikacio: KKV Projekt es Feladat Automatizalas

## Hatter

A projektkezelesi blokk a heti feladatosztast, a heti statusz-zarast es a hatarido-csuszasi riasztast automatizalja.

## Scope

- WF-PROJEKT-1 hetfoi feladatdelegalo es penteki allapotriport
- WF-PROJEKT-2 hatarido csuszas riaszto
- Supabase vagy Notion feladatforras
- Gmail eszkalacios csatorna

## Acceptance kriteriumok

- Hetfo reggel szemelyre szabott feladatlista kuldheto minden felelosnek.
- Penteki allapotriport AI tamogatassal osszegezheto.
- A lejart vagy 2 napon beluli feladatok napi riasztast adnak.
- 3+ napos csuszas eseten vezeto is kap ertesitest.
