# Product Definition

## Vision
The Brunella Agent System (BAS) is an AI multi-agent system designed for automating software development using local LLMs (Ollama), GitHub Models (gpt-4.1), the MCP protocol, and a hybrid Node.js/Python architecture.

## Stratégiai Jövőkép (Fő Irányvonalak)

### 1. Eseményvezérelt, Proaktív Működés (Zero-Prompt AI)
A Brunella nem vár utasításra. Folyamatosan monitorozza a környezetét (emailek, GitHub repók, szerverek, naptár).
*   **Hatás**: Automatikus hibajavítás és fejlesztés; az ágens elvégzi a munka oroszlánrészét, mielőtt a felhasználó észlelné a szükségletet, és csak jóváhagyást kér.

### 2. Folyamatos Önfejlesztés (Continuous Self-Improvement)
A rendszer a telemetriai adatokból és sikeres akciókból automatikusan szintetikus tanítóadatbázist generál.
*   **Hatás**: Saját Small Language Model-ek (SLM) finomhangolása (reflex-modellek), amivel csökken a függőség a drága, nagy LLM-ektől, és nő a válaszidő sebessége.

### 3. Dinamikus, Eldobható Ágensek (Dynamic Agent Spawning)
A fix szerepkörök helyett a rendszer igény szerint, menet közben hoz létre specializált ágenseket.
*   **Hatás**: Végtelenül skálázható, adaptív intelligencia, amely specifikus MCP toolokkal felvértezve old meg egyedi, sosem látott kihívásokat, majd a feladat végeztével törlődik.

### 4. Ágens-Ágens (B2B) Hálózatok (Federated MCP)
Biztonságos, titkosított kommunikáció más rendszerek ágenseivel.
*   **Hatás**: Autonóm tárgyalás és üzletkötés (pl. erőforrás-bővítés, szoftverlicenc beszerzés) külső szolgáltatók ágenseivel.

## Target Audience
The primary audience for this system is Individual Devs, focusing on individual developers looking to automate personal coding and research workflows.
