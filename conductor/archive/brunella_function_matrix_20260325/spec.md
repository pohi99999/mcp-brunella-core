# Spec — Brunella teljes funkció- és tulajdonságmátrix

## Elvárt eredmény
A `funkcio.md` legyen a Brunella rendszer nagyfelbontású funkciótérképe, amely lefedi:
- architektúrát és futtatási módokat,
- agent ökoszisztémát,
- MCP tool és REST API capability-ket,
- dashboard és CLI felületeket,
- Python alrendszert,
- Cloudflare / edge / remote capability-ket,
- memória-, adat- és tudásrétegeket,
- biztonsági és observability képességeket,
- külső integrációkat,
- fejlesztési és operációs workflow-kat.

## Minőségi elvárás
A dokumentum ne csak felsoroljon, hanem kategorizáljon, mátrixszerűen rendszerezzen, és hivatkozzon a kulcsfájlokra / mappákra.
