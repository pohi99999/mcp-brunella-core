# Architecture Decision Records (ADR)

Ez a mappa a Brunella rendszer fontos architekturális döntéseit tárolja.

## Formátum

- `0001-...md`, `0002-...md`, ...
- Állapot: `proposed` | `accepted` | `deprecated` | `superseded`
- Szekciók:
  1. Context
  2. Decision
  3. Consequences
