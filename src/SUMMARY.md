# 📁 Source Code (src) - SUMMARY

Ez a mappa tartalmazza a Brunella Core és az ügynökrendszer elsődleges TypeScript forráskódját.

## 🗂️ Struktúra
- **`agents/`**: Ügynökök definíciói, logikája és a központi regiszter.
- **`cli/`**: A parancssori interfész implementációja és parancsai.
- **`core/`**: Alapvető rendszermodulok (pl. LLM kliens).
- **`server/`**: Az MCP és Express szerver logikája.
- **`tools/`**: Az ügynökök által használt MCP eszközök (tools) gyűjteménye.
- **`utils/`**: Segédfüggvények (auth, adatbázis kezelés, naplózás).
- **`dashboard/`**: A React alapú felhasználói felület forráskódja.

## 🛠️ Kulcsfájlok
- `index.ts`: A rendszer belépési pontja.
- `cli.ts`: A Brunella CLI fő fájlja.
- `interactive.ts`: Az interaktív menürendszer.
