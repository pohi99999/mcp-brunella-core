# Plan — Brunella teljes funkció- és tulajdonságmátrix

## Cél
A repó gyökerében egy `funkcio.md` dokumentum létrehozása, amely a Brunella Agent System teljes képességkészletét, szolgáltatásait, logikai alrendszereit, memória-rétegeit, MCP integrációit és külső kapcsolatait egyetlen áttekintő mátrixban összegzi.

## Fázisok

### Phase 1 — Források feltárása
- [ ] README és fő architektúra-dokumentumok áttekintése
- [ ] Agent, tool, route, dashboard, Python és Cloudflare struktúrák feltérképezése
- [ ] Kulcs capability domain-ek azonosítása

### Phase 2 — Mátrix összeállítása
- [ ] Képességkategóriák kialakítása
- [ ] Alrendszerek, integrációk és runtime komponensek listázása
- [ ] Memória-, adat- és biztonsági réteg dokumentálása

### Phase 3 — Dokumentum megírása
- [ ] `funkcio.md` létrehozása a repo gyökerében
- [ ] Mátrixok, táblák, capability listák és hivatkozások beépítése
- [ ] Konzisztencia-ellenőrzés és nyelvi tisztítás
